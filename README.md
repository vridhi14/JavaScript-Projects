## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/vridhi14/JavaScript-Projects.git
```

2. Navigate to the project folder

```bash
cd JavaScript-Projects
```

3. Open any project in your browser using **Live Server** or simply open the `index.html` file.
